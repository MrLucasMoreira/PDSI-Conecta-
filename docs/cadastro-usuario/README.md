## Escopo do Incremento

A documentação contempla os seguintes fluxos:

- cadastro de usuário na plataforma;
- visualização de organizações disponíveis;
- solicitação e acompanhamento de acesso a uma organização;
- visualização de solicitações pendentes pelo administrador da organização;
- aprovação ou rejeição de solicitações;
- visualização e remoção de membros da organização.
